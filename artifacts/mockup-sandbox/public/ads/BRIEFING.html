Designer Pre-Submission Checklist

  • Document rebuilt in InDesign (or equivalent) at correct trim size with 3 mm bleed on all sides
  • Background image replaced with licensed hi-res file at 300 dpi minimum
  • All colours converted to CMYK — gold accent verified at proof stage
  • Inter and Playfair Display fonts downloaded, embedded or outlined
  • PDF exported as PDF/X-1a or PDF 1.3 (confirm format with Jamie McGrorty)
  • Physical or digital proof reviewed and approved before submission
  • QR code re-generated at print resolution pointing to https://bdefarmtrac.co.uk
  • File named clearly: e.g. BDE-FarmTrac-HalfPage-FINAL.pdf / BDE-FarmTrac-FullPage-FINAL.pdf
