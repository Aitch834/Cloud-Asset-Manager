QR Code

Both ads include a QR code linking to https://bdefarmtrac.co.uk. The version embedded in the HTML files is low-resolution (screen only). For print, regenerate the QR code at high resolution using any free QR generator (e.g. qr-code-generator.com) — export as SVG or PNG at 300 dpi minimum, pointing to https://bdefarmtrac.co.uk.

Submission Checklist

  • Confirm exact trim and bleed sizes with Jamie before building the print PDF
  • Confirm copy deadline for the intended issue(s)
  • Confirm Jamie's preferred file delivery method (email / WeTransfer / upload portal)
  • Source hi-res background image (300 dpi) to replace the Pexels placeholder

  • Rebuild ad layout at correct trim + bleed in InDesign or equivalent desktop publishing software
  • Convert all colours to CMYK and verify gold at proof stage

  • Export as PDF/X-1a (or format confirmed by Jamie)
